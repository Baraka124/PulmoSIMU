# INF05D — Multi-structure reconstruction worker (offline)
Preserves original INF04 airway pipeline and v1 hosted package. New independent package contract pulmo.multi-structure-package/1 is **not** accepted by the v1 publisher or catalogue yet. No database change. 
Input is exact-grid uncompressed CT NIfTI (for DICOM use H01 convert first). Supply any subset of masks named RUL/RML/RLL/LUL/LLL/airway_lumen/pulmonary_artery/pulmonary_vein/lung.nii[.gz] with actual provider/version, or use pinned TotalSegmentator 2.13.0 total ROI lobe and lung_vessels tasks. Model labels lung_airways, lung_arteries, lung_veins; never use wall as lumen. Inference runtime not yet tested. Missing supplied structures are explicitly recorded; no inferred filler. Derive union only with five lobes and no independently supplied lung mask; overlap excess memberships reported, not corrected. 
python -m pip install -r requirements-reconstruction.txt
python experimental/anatomy/multistructure_worker.py CT.nii NEW_OUTPUT --study-id UUID --mask-dir MASKS --provider "actual provider" --version "actual version"
Optional model: install requirements-inference.txt in separate reviewed inference environment and omit mask-dir/provider/version, choose --device cpu or gpu. Verify provider model licenses and weights. 
Outputs: original source.nii, independent masks/topology/GLBs and per-structure reports, combined pulmonary.glb with named meshes and reconstruction.json in common CT-centered metric RAS transform. Whole-lung shell omitted from combined scene if all five lobes present to avoid duplicate overlapping shell. Open source.nii, pulmonary.glb, reconstruction.json manually in the Source Anatomy Laboratory, isolate named meshes with existing structure selector. Airway-specific route requires separate matching airway geometry and mask; combined manifest is not a procedure source. All outputs pending review. Limits: 150M CT voxels, 80M non-airway foreground, 150M cropped voxels, 3M combined faces, 150MiB GLB. High-memory offline worker; no silent resampling or smoothing. Not yet tested on full-sized real CT. Do not upload this package through v1 publisher; future cloud schema/streaming contract required. 
Model class sources: https://github.com/wasserth/TotalSegmentator/blob/master/totalsegmentator/map_to_binary.py and release 2.13.0 changelog.
