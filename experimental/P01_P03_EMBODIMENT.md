# P01–P03 | Embodied reference XR foundation

Existing procedural engine and source gates preserved. P01: tracked 25-joint hand geometry, low-poly glove surfaces, head-relative inferred torso, pelvis, upper/lower arms and seated/standing leg/foot approximation in VR. Controller pose is an endpoint, not individual finger data. Hands and arms disappear on lost tracking; no invented joint poses. Body is a deliberately approximate anthropometric visualization with fixed floor-relative feet, not measured lower-body motion, realistic skinned avatar or true body ownership validation. VR only; passthrough does not cover real hands with virtual body. All avatar geometry excluded from endoscopic render. BODY toggle in Expert tools > Virtual workspace > Workspace options.

P02: experimental HAND PROCEDURE toggle on same menu, off by default and reference VR only. With no controller gamepad input, open hands first, pinch near parked handle with right, hold and move wrist to map bounded angulation; left pinch near shaft guide and move relative to handle for bounded feed. Near acquisition, release-before-reacquisition, no stale displacement, no physical sensor override, no accessory or panel editing. Original route and instrument constraints remain in charge. Menu pinch retains precedence; direct hand branch selection disabled in hand mode (use existing branch controls). Does not yet solve hand mesh/instrument collision, grip-surface fit, physical flexible shaft coupling, independent EBUS probe or precise thumb lever. The displayed handheld shaft is the existing illustrative model; Q will address it.

P03: approximate two-link elbow estimate, head-relative posture, tracking loss and discontinuity release. Fixed anthropometric assumptions, not calibrated to an individual's anatomy; no walking gait or actual feet tracking. No avatar mirror. Haptic hardware absent. Controller fallback unchanged. Test: node --test experimental/tests/p03-embodiment.test.mjs. Test actual Quest 2 hand visibility, menu conflicts, pickup/release, occlusion, arm fit and frame time before acceptance; no claims of physical validation.
