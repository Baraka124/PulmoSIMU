# UI10 | Precision scientific visualization

Adds a persistent scientific layer strip in the source workstation. Original CT pixels, windowing, segmentation editing, calculations, identifiers and export formats unchanged. Separate pointer-transparent overlay canvases share the source image raster and object-fit; toggles do not rerun the CT raster. Mask switch synchronizes with original segmentation switch. Route in cyan, phase-0 shaft solution in dashed amber. Geometry is clipped to the selected one-voxel slab, not a maximum-intensity projection or 3D registration. Exact current CT/mask identity and unchanged source mask required. Expiration shaft excluded rather than shown as inspiration anatomy. No new source data or patient-specific procedure authority.

Paired field: 7x7 sample grid per slice, from existing bound deformation mapper, only valid positive-Jacobian samples within moving-volume support. Projected displacement in fixed CT axes, arrow length capped at 18% raster width for legibility; arrows are schematic, not scale measurements. Out-of-plane motion omitted in projection; full point displacement remains in original inspector. Jacobian mode shows sampled compression/expansion, blue below 1 and amber above 1, log magnitude opacity capped at factor 2. No interpolated heatmap, actual measured respiratory motion or new surface deformation. Horizontal scale only with explicit mm source and valid affine; label based on original voxel spacing. Clicks in letterbox margins ignored rather than snapping to edge. Overlay scheduling coalesced by animation frame; no extra CT redraw on route/field/shaft toggles. Existing exact source constraints remain. The present views retain existing voxel-axis slices, not anatomically reoriented MPR for arbitrary oblique acquisitions.

Test node --test experimental/tests/ui10-scientific-view.test.mjs. Isolated projection, slab, mapper and scale tests; browser rendering and actual CT/field dataset not tested. No CFD, tissue mechanics or measured force visualized in this batch. Production deployment not performed.
