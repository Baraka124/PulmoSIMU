# V01–V03 | Source airway anatomy fidelity

V01: reconstruct the original exact I-phase binary airway mask (no invented structures, no gap repair or smoothing). Run offline Python 3.11+ with numpy, nibabel, scipy, scikit-image:
```
python experimental/anatomy/anatomy_fidelity.py ORIGINAL_CT.nii PREPARED_MASK_DIR NEW_OUTPUT_DIR
```
PREPARED_MASK_DIR contains mask.json and mask.raw from segmentation_pipeline.py. This is not an automated CT segmentation engine. The source and mask hashes, shape, explicit mm sform, scalar calibration and orthogonal spacing are checked. Foreground max 5M voxels, cropped padded grid max 25M, mesh max 1.5M triangles. Marching cubes at 0.5, no smoothing or mesh repair. Centered right-handed glTF metres with explicit inverse-compatible RAS transform. airway.glb + reconstruction.json are loadable in Study & sources. FOV boundary flags distinguish artificial zero-padding closure from actual anatomy; surface volume is a geometric estimate. All components retained.

V02: optional operator-authored landmark input, not inferred anatomy. Add --landmarks landmarks.json. Schema pulmosimu.anatomy-landmarks/1; ct_sha256 and mask_sha256 exact, landmarks maps oral_cavity, pharynx, larynx, trachea, distal_airway to distinct integer [i,j,k] coordinates of the same source; sections optional list of up to 32 objects with center_voxel, normal_ras (explicit physical normal), radius_mm and step_mm. Only report if all five marked voxels are in the same 6-connected component; this does not prove anatomical labels, ordered path, coverage or airway-specific connectivity (e.g. leakage can connect regions). If scan excludes upper airway, omit landmarks. No extrapolation or replacing reference oral guide. No patient-specific procedure unlock.

V03: report foreground volume, component count, largest-component fraction, mesh area, enclosed volume, boundary and nonmanifold edges, source boundary contact, optional center-connected cross-sectional nearest-voxel samples and area-equivalent diameter. No inferred minimum caliber or continuous collision clearance. Plane radius 2–40 mm, raster step .25–2 mm. Reject diameter if region touches raster disk rim or disk exits source FOV. Coarse voxel resolution and oblique nearest-neighbor sampling limit accuracy. Mesh winding corrected by aggregate signed volume, not per-component orientation certification. No clinical validity claim.
