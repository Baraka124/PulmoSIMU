# S01–S03 | Local physical–virtual bench registration

S01: manual rigid alignment to a horizontal 200 x 150 mm measured rectangular jig. Origin, +X (200 mm), +Z (150 mm) and independent opposite corner must be touched with the calibrated pointer. Length tolerance 8 mm, orthogonality |dot| <= .06, up vector >= .85, fourth point residual <= 12 mm. These are provisional research thresholds, not metrology certification. Ordered landmarks establish a right-handed frame without scale fitting. Reference anatomy can be explicitly aligned above jig in MR at existing nominal physical scale; no CT/patient registration or procedure control. Alignment locks ordinary grabbing, analog anatomy changes, recenter and history until clear. Existing MR anchor is released for explicit manual alignment. No persistent anchors or clinical alignment. Session/reference-space change or viewer pose loss clears calibration and hides aligned model.

S02: controller-mounted passive pointer pivot calibration. Keep its physical tip fixed at one target and capture 5 distinct controller orientations (4 fit, 1 independent check). Least squares solves controller-local offset and fixed pivot. Reject degeneracy, offset outside 15–350 mm, fit RMS >6 mm or holdout >12 mm. Use a rigid, lightweight, non-sharp attachment, not a clinical device. Local visual pointer uses actual tracked grip and computed tip; it does not drive scope, sense force, identify physical instrument, guarantee mount rigidity or provide active haptics. Controller must be present and trackable; no hand-only pivot claim. Real measurements required.

S03: existing hit test and anchor lifecycle retained. Optional plane-detection requested for MR; plane-depth mask is explicit opt-in. Only actual valid runtime polygons and poses, bounded to 8 planes and 64 vertices, rendered colorless with depth writes; missing/invalid plane data clears mask. No per-pixel depth, camera access, real-world collision solver, or claimed occlusion on Quest 2. Pointer and jig visual available in VR as augmented virtuality of tracked physical proxy; excluded along with occluder from original endoscopic feed. No raw room positions or pose traces exported in calibration status, only counts and residuals.

Workflow: enter MR placement or Expert tools > Virtual workspace > Workspace options > Spatial calibration. Select pointer pivot; arm each capture from menu, then press right trigger while holding tip at fixed target; vary wrist orientation. Select jig landmarks and repeat 4 ordered captures. Select align reference in MR; clear/unlock to return to unregistered preview. The pointer can be displayed separately. Optional plane mask requires runtime actual plane data. Existing viewport-jump shortcut remains in workspace options, alongside the calibration entry. Session reference-space reset events also invalidate alignment.

Run node --test experimental/tests/s03-spatial-calibration.test.mjs. Actual XR rendering, mount stability, device availability, tracking error, plane depth compositing and physical alignment require headset and physical bench verification. No deployment or hardware acceptance implied.
