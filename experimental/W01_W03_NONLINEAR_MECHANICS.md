# W01–W03 | Nonlinear instrument mechanics

Independent original-source research solver in the Instrument mechanics task; retains L03 fixed-endpoint solver and all existing immersive controls. W01: discrete isotropic extensible rod, finite-angle tangent bending energy EI/l*(1-u·v), axial strain EA/l, scalar material spin with GJ/l. Analytic position and spin gradients. Resample 4–24 nodes; original chord lengths are rest lengths. A weak route anchor (0.02 N/mm) is an explicit numerical assumption. This is not a full Cosserat rod with director frames, shear, anisotropy or geometric torsion coupling.

W02: original exact unchanged source mask signed distance, nodal and midpoint wall penalty, provisional assumed stiffness. Incremental regularized Coulomb potential uses prior nodal normal load and tangential displacement plus radius-weighted spin. Normal load frozen over incremental step; no evolving stick-slip, validated friction law or distributed tissue deformation. Sampled contact only, no swept collision. Censored outside support rejected. 16 million estimated voxel-neighborhood visits maximum, original maskContact per-query limit retained. No physical force measurement; reaction and torque are model gradients, not calibrated insertion forces. Unresolved gradients and residuals reported; termination is not a convergence certificate.

W03: relax baseline with first two positions clamped and distal end free; translate proximal two nodes by ±2 mm along initial direction, prescribe scalar roll ±45°, then relax free position/spin by bounded descent (12 default iterations, 16 max). The same material discretization is displaced; no material insertion/retraction through mouth, new shaft length or tip steering. No live control or actuator connection. Report distal displacement and spin, energy terms, residuals, modeled reactions, baseline/response geometry, exact route JSON SHA-256 in UI export. Original phase only, separate from expiration L result, no patient-specific navigation unlock.

UI: Source laboratory > Instrument mechanics > Nonlinear instrument mechanics. Plan original source route first, use EI/wall/friction from L controls, set GJ/EA/translation/roll. Explicit calculation; export report and inspect baseline vs response RAS projection. Changes to route or controls invalidate solution. No overlays masquerading as actual instrument pose. Browser integration, numerical mesh convergence, experimental material parameters, force/torque comparison and real device validation remain pending. Tests: node --test experimental/tests/w03-nonlinear-shaft.test.mjs. Four isolated numerical tests run via adapted harness, not native Node.
