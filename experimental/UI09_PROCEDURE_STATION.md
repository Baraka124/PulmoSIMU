# UI09 | Physical procedural workstation

Endoscopic display retains its full original image plane (.94 x .529 m nominal) when EBUS is enabled; original camera, render target, optical material, status strips and native compositor eligibility remain unchanged. No added optical overlay. Independent EBUS display (.64 x .69 m nominal bezel) with existing 512x512 radial/convex canvas, matching chassis, dedicated identification strip and four extruded controls (feed/retract/rotate/range). Buttons use original action handlers and source safety gates; selection is a pointer hit, not a physical hardware command. Mode and acoustic coupling still available in Imaging lab. Display is included in bounded composition, explicit panel editing, pin/reset and size controls. Composition is an angular heuristic, not guaranteed nonoverlap. Existing guide remains a separate instrument surface and original source-derived procedural guidance.

VR studio equipment: floor-supported endoscopy tower with base, castors, equipment modules, column and mounting neck; smaller ultrasound stand. Supports adapt to deliberate display arrangement and are suppressed when outside provisional height, room or head-distance limits, or near the approximate reference patient bed. The floor is existing estimated room floor. No physical collision, simulated equipment actuation, manufacturer replication or patient-room reconstruction. Focus mode/MR do not render floor stands. Unavailable support leaves a freestanding display view rather than drawing an invalid support. Entire secondary display and supports excluded from endoscopic render; hide on mode exit/tracking loss/session end. Existing EBUS numerical model and gates not changed.

Native compositor still uses original conservative eligibility (radial enabled disables native path); no new layer claims. UI11 requires physical headset assessment of readability, stand geometry, panel placement, control ergonomics, GPU performance and full integration. Test: node --test experimental/tests/ui09-procedure-tower.test.mjs. Source syntax and isolated envelope tests, not actual GPU or headset tests.
