# R01–R03 | Embodied reference patient station

R01: optional VR reference-only procedural station, accessible from Bronchoscopy > Procedure station > Patient station. A nominal 1.72 m adult manikin and 2.10 m bed are placed once in world coordinates on the existing estimated room floor. Supine reference frame maps source X to transverse, Y to cranial, Z to anterior (up); original reference trachea root is anchored at neck with mmPerSceneUnit/1000 scale. Original airway/route state remains sole engine; no patient-specific anatomy, independently measured anthropometry or actual mannequin registration. Existing comfort-scale transform saved and restored on leaving station. Plinth hidden while station active. Explicitly reframe by exiting/re-entering; recenter changes panels only while in station.

R02: approximate mouth landmark, external visual shaft routed to mouth, optional illustrative internal connector to original trachea in transparent/internal views. No reconstructed oral/pharyngeal anatomy, continuous external shaft physics or full-body collision; connector is not length-conserving. Operator zone checks tracked head projection outside bed and horizontal distance 0.28–1.15 m from mouth, nominal height above neck 0.18–1.40 m. Reference advance/retract/branch/steering and positive probe feed gated by operator location; manual and hand/controller modes preserved. This is an ergonomic prototype, not a physical or clinical clearance test. No artificial locomotion through bed; room-scale walking is limited by actual headset guardian and safe physical surroundings. Native scope/guide gates remain active.

R03: external opaque manikin, transparent shell and internal anatomy display modes; original anatomy is not replaced or hidden by source-state flags. Opaque shell may not enclose every original anatomy surface; inspect actual rendering. Manikin excluded from offscreen endoscope image, and hidden on pose loss. Existing MR path unaffected. No patient identifier or data.

Tests: node --test experimental/tests/r03-reference-patient.test.mjs. Actual Quest placement, mouth alignment, seated reach, source orientation, interaction, occlusion and visual performance require testing. Fixed-scale reference model not accepted anatomical fit. Do not use to guide clinical procedure.
