# U01–U03 | Reference motion recording and collaborative review foundation

U01: explicit opt-in 10 Hz recording (actual frame-limited), maximum 6000 samples or 10 minutes, reference VR procedure only. Stores relative time, reference tip mm, segment and normalized position, wrapped roll, deflection, EBUS state and extension, optional geometric risk, tracked wrist or controller grip in head-relative axes and approximate grip state. No absolute headset/room coordinates, names, video, CT or raw sensor stream. Head-relative hand trajectories remain potentially sensitive motion information. Left bare-hand grip indicator is the existing approximate hand-grasp flag, not a validated instrument-contact measurement. Discontinuities/gaps and branch transitions not bridged. Tracking loss marks a break; mode exit stops recording. Data in memory only; separate explicit local JSON export. Main session report includes counts only. Imported records are allowlisted, bounded, read-only and never drive procedure or haptics. No cryptographic source attestation.

U02: time scrub and playback in XR motion review page and separate desktop motion-review.html workstation. Projected tip trajectory with yaw/elevation and separate head-relative hands panel, not an anatomically registered 3D avatar reconstruction. Metrics: elapsed/active time, within-segment tip travel, sampled peak speed, hand-relative travel (only same tracked source and bounded intervals), roll travel, radial probe travel, grip transitions, proportion of available geometric risk samples >=.5, discontinuities. No force or competency scoring. Replay does not change scope or original anatomy.

U03: portable reference recording for manual collaborative review. Optional explicitly activated BroadcastChannel sends allowlisted sparse reference snapshots at up to 2 Hz with randomly generated local 12-character code. Same origin and browser profile/storage partition only, no server or cross-device WebRTC, no account, authentication or guaranteed privacy from other same-origin scripts. Local observer does not send any commands. Sparse samples are marked discontinuous and not treated as continuous motion. Closing or stopping capture closes channel; no automatic upload. True multi-headset collaboration, remote avatars, encrypted transport/access control, synchronized spatial registration and network acceptance are NOT implemented.

Access in XR: Bronchoscopy > Procedure station > Working channel > Instrument trace > Haptic lab > Motion review; or anatomy Expert tools > Virtual workspace > Workspace options > Research evidence > Motion review. Start recording in reference VR procedure; stop/review, optionally enable local observer while recording; export in desktop Session tools > Reference motion review. Independent reviewer at experimental/motion-review.html. Exit XR for local import/export. Run node --test experimental/tests/u03-session-review.test.mjs. Actual headset interaction and browser live channel need testing.

This completes the P–U software foundation, not physical acceptance. Proceed to UI07–UI11 with existing gates intact.
