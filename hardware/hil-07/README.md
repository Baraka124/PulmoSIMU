This is a numerical acceptance assistant, not sensor firmware, validated calibration or live hardware bridge.
Run node hardware/hil-07/multi-axis.mjs measured.json report.json.

The example is schema-only; thresholds must be justified and chosen by the engineering reviewer. Record independent ground truth, instrument, units, environmental conditions, device identity and operator; collect paired up/down fit levels and independent paired check levels on each axis. Unwrap angular observations within the selected calibration range before fitting; do not cross the angular wrap. Independent repeated trials and calibration uncertainty remain necessary. The script checks fit span, holdout residuals, extrapolation and paired hysteresis; it will not create BENCH/1 frames, drive hardware or certify physical accuracy.
