# HIL-05 / XR-31 | Local registration and numerical contact interface
The registration tool computes a rigid frame from exactly three non-collinear matched fit landmarks in millimetres and checks it on two or more independent landmarks. It is a three-point basis method, not a least-squares multi-point rigid fit. The 3 mm provisional residual criterion is an engineering assumption, not a clinical specification. Use independent measured landmarks with known coordinate handedness, record instrument and fixture provenance, and do not substitute synthetic values for physical acceptance.
Run: node hardware/hil-05/register.mjs measured-landmarks.json report.json
Input object has fit and check arrays of {sourceMm:[x,y,z],targetMm:[x,y,z]}. No overwriting reports. No browser connection, no physical device control. The XR observer records only aggregate sample displacements, tracking interruptions and timestamp discontinuities; these are not localization error or uncertainty estimates. A real tracked instrument and independent ground truth are required.
The contact interface maps negative sampled reference-shaft margin to a bounded dimensionless risk indicator. It never calculates physical force or torque, and does not connect to any brake, motor or network endpoint. Real contact-to-resistance calibration requires measured forces, reviewed limits, release mechanism, guards and independent bench validation before headset use.
