# HIL-04 | Passive resistance bench, design study
Draft passive desktop fixture, not a haptic device or manufacturing-ready assembly. The CAD contains a base, shaft guide and guard coupon. Rollers, independent encoders, load cell, manual quick release, pinch guards and commercially sourced resistance element are deliberately unspecified until component selection and risk review. No motor or brake actuation; no unattended operation, headset use or patient contact. Do not assemble or apply resistance before independent inspection and manual release testing.
The numerical passive model opposes movement and accounts for dissipated energy; it never emits hardware commands. Assumed drag parameters are not measured instrument resistance or operating limits. Bench testing should record bidirectional measured insertion force and rotation torque, backlash, slip, repeatability and release behavior, first without a headset. Passive-only architecture and emergency manual release are prerequisites before any later controlled braking design. CAD not rendered or fit-checked.
