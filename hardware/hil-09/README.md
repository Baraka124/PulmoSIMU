# HIL-09 — physical evidence and integration readiness
This is a review aid only. The software does not assert that a device has been fabricated, calibrated or tested.
Required records: mechanicalFit (measured fit and tolerances), sensorSelection (part numbers, axes and independent reference instruments), electricalReview (voltage, current, wiring and isolation), captureQA (HIL-08), calibrationQA (HIL-07), releaseTest (manual safe release, no headset), independentReview (signed engineering review).
Each record has role, relative file, sha256, reviewer, date. Run node hardware/hil-09/evidence.mjs manifest.json report.json. Byte matching only confirms the file inventory; it cannot authenticate signatures, measurements, calibration or approval. No BENCH/1 output, no hardware commands. Keep prototype passive and separate from clinical devices. Live simulator coupling remains independently reviewed and manually armed with dead-man and stale input fail-closed behavior. No patient use.
