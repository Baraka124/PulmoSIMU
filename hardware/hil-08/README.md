# HIL-08 | Raw four-axis acquisition acceptance specification
Offline capture-qa.mjs checks strictly increasing per-channel timestamps, missing observations, channel gaps and observed skew. Use measured common-clock timestamped raw capture; no clock synchronization is inferred, no synthetic data is accepted as physical evidence. Run node hardware/hil-08/capture-qa.mjs capture.json report.json. Input channels object keys insertionMm, rotationDeg, tipPitchDeg, tipYawDeg; each array contains {tMs,raw}. limits specifies maxSkewMs, maxGapMs (engineering assumptions to justify experimentally). Match is nearest timestamp, not interpolation; repeated matches are possible and not proof of independent samples. Hardware architecture: independent linear encoder, shaft-angle encoder and two distal-angle channels, common monotonic microcontroller clock, local raw acquisition, isolated read-only transport. Choose actual sensor parts, resolve supply voltages, pin mapping, mechanical dimensions and cable strain relief before PCB or firmware changes. Use independently measured reference positions/angles and HIL-07 calibration; no automatic BENCH/1 export, live actuation or manufacture claim.
