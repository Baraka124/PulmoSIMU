# HIL-03 | Passive calibration and connectivity
Draft local calibration tooling for the raw angle sensor. No physical device, motor or live network bridge is connected. Run with Node 18+:
    node hardware/hil-03/calibrate.mjs measured-sweep.json report.json
Input is an array of independently observed rows: adc (integer 0–4095), referenceDeg (independent measured angle), role ("fit" or "check"), direction ("up" or "down"). Collect at least 3 paired up/down fit levels and 3 independent check levels within the ADC range; use separate trials and record the reference instrument, environmental conditions, device ID, operator and date outside this anonymized data file. No synthetic rows should be used for acceptance. Provisional check and hysteresis targets are each 5 degrees, not clinical limits. The script fits a linear model, evaluates independent checks and hysteresis, rejects extrapolation and writes a report without overwriting an existing file.
The draft printed angle fixture is a holding/indexing aid only. It is not a calibrated reference. CAD not rendered or physically checked.
The existing browser BENCH/1 protocol still requires insertion, shaft rotation, tip pitch and tip yaw. Lever-angle calibration is not equivalent to distal tip measurement. This tool never exports BENCH/1, never controls hardware, and never claims the other axes are present. HIL-03 connectivity is pending measured channels, calibration and local bridge implementation.
